LOCAL SERVICE COMMANDS (macOS / zsh)
============================================================

Run each service in a SEPARATE terminal.
Stop: press Ctrl+C in that service terminal.
Restart: repeat its daily startup commands below.
Install packages only on first setup or when dependencies change.
These commands start services; they do not train models.

CONFIGURATION BEFORE STARTING
-----------------------------
Configure each backend .env with its database and service URLs.
MongoDB and any configured external dependencies must be reachable.
Use the same JWT_SECRET as authService for services validating its tokens.
Do not generate different JWT secrets for each service.

Provider ML prerequisite:
In Provider_Service/ML_Engine/src/predictor.py, replace the Windows MODEL_DIR assignment with:
MODEL_DIR = os.path.join(os.path.dirname(os.path.abspath(__file__)), "saved")
Ensure trained model files exist in that saved folder.
Set MONGO_URI in Provider_Service/ML_Engine/.env.

Seeker image classifier prerequisite:
Set JWT_SECRET and MONGO_URI in Seeker_Service/service-image-classifier/.env.
Set ALGORITHM=HS256 if that is the algorithm used by authService.
The reported startup error was caused by the missing JWT_SECRET.

NOTES
------------------------------------------------------------
Provider_Service itself has no npm start script; use Provider_Service/Backend.
Backend ports come from their code and .env configuration.
If a port is already occupied, stop the earlier process in its terminal with Ctrl+C.
If a virtual environment is already active in the correct folder, rerun only the Python startup command.
Use deactivate to leave a Python virtual environment after stopping a service.
No services were started while preparing this guide.
